// 01 — What it does

Five Modules.
One Agentic System.

01
Invoice Reconciliation
AI-powered matching of invoices vs. payments. Flags unpaid vendors, computes discrepancies, and generates reconciliation summaries with Plotly bar charts.
🧾
02
Insurance Claims Reconciliation
Matches insurance claims against settlement records. Identifies pending exposures, highest-risk claimants, and insurer-wise volume breakdowns.
🏥
03
Credit Memo Builder
Automated generation of structured credit memos from input data — formatted, AI-reviewed, and export-ready for finance teams.
📝
04
Budget Forecasting
Analyzes monthly income and expense trends, computes net surplus, expense ratios, and projects forward-looking budget scenarios.
📊
05
Annual Report Analyzer
Ingests uploaded annual reports (PDF), extracts financial highlights using PDFPlumber + Gemini AI, and surfaces key metrics and risks.
📄

// 03 — How it was built

The Stack.

🐍
Python
Core application logic, data processing pipelines, file handling, and module orchestration.
🎛
Streamlit
Full web UI with multi-page routing, file uploaders, interactive dashboards, and live data rendering.
✨
Google Gemini AI
gemini-2.5-flash-lite powering natural language analysis, summaries, and intelligent recommendations.
🐼
Pandas
Data reconciliation, merging datasets, computing variances, and financial aggregations.
📈
Plotly
Interactive bar, pie, and line charts embedded across all 5 modules plus a summary Dashboard.
📄
PDFPlumber
Extracts structured text and tables from uploaded annual reports and financial PDFs.
🤗
Hugging Face Spaces
Live cloud deployment — publicly accessible, always-on, zero infrastructure management.
🐙
GitHub
Version control, .gitignore for API key security, Phase 1 → Version 2 commit history.
