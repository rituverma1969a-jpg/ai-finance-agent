\## 📊 What it does



| Module | Description |

|---|---|

| 🧾 Invoice Reconciliation | Automatically matches invoices to payments and flags unpaid ones with AI analysis |

| 🏥 Insurance Reconciliation | Compares insurance claims vs settlements, identifies high variance cases |

| 📝 Credit Memo Builder | Generates professional credit memos instantly with one click |

| 📈 Budget Forecast | Produces 3-6 month financial projections with risk analysis |

| 📄 Annual Report Analyzer | Reads any company PDF and answers questions about it |

\## 🚀 How to Run Locally



1\. Clone this repository

```bash

git clone https://github.com/rituverma1969a-jpg/ai-finance-agent.git

cd ai-finance-agent

```



2\. Install dependencies

```bash

pip install -r requirements.txt

```



3\. Create `.env` file and add your API key

```

GOOGLE\_API\_KEY=your\_key\_here

```



4\. Run the app

```bash

py -m streamlit run app\_main.py

```
